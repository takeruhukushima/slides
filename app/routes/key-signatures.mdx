五線譜の**調号**から、長調 (Dur) と短調 (moll) を一覧に

## 読み方 — 調号のしくみ

- **調号**（音部記号のとなりの ♯／♭ の並び）が、その曲の音階（スケール）を決める
- 同じ調号を共有する長調と短調を **平行調 (relative key)** と呼ぶ
- **♯ が付く順序**：ファ → ド → ソ → レ → ラ → ミ → シ
- **♭ が付く順序**：シ → ミ → ラ → レ → ソ → ド → ファ（♯の逆）

::right::

## 五度圏 — Circle of Fifths

<svg class="cof" viewBox="0 0 400 400" role="img" aria-label="五度圏">
  <circle class="cof-ring" cx="200" cy="200" r="176" />
  <circle class="cof-ring" cx="200" cy="200" r="132" />
  <circle class="cof-ring" cx="200" cy="200" r="86" />
  {circle.map((e, i) => {
    const [x1, y1] = pt(86, i * 30)
    const [x2, y2] = pt(176, i * 30)
    const [mx, my] = pt(154, i * 30)
    const [nx, ny] = pt(109, i * 30)
    return (
      <g key={i}>
        <line class="cof-spoke" x1={x1} y1={y1} x2={x2} y2={y2} />
        <text class={i === 0 ? 'cof-maj cof-c' : 'cof-maj'} x={mx} y={my} font-size="22">{e.maj}</text>
        <text class="cof-min" x={nx} y={ny} font-size="16">{e.min}</text>
      </g>
    )
  })}
  <text class="cof-min" x="200" y="200" font-size="13">♯ →</text>
</svg>

::right::

- 時計回りに完全5度ずつ進むと **♯ が1つずつ増える**（C→G→D…）
- 反時計回りは完全4度＝♭ が1つずつ増える（C→F→B♭…）
- 外側が**長調**、内側が**平行短調**
- 底部（6時）は **G♭ ＝ F♯** の異名同音。表記で ♭6／♯6 を区別する

## スケールを実音で

同じ「ドレミファソラシド」でも、主音（開始音）と調号が変わる。調号に含まれる音には臨時記号を書かない。

<div class="vf-stave" data-key="C" data-scale="c/4,d/4,e/4,f/4,g/4,a/4,b/4,c/5" data-width="440" data-height="120">♪</div>

**ハ長調 C major** — 調号なし。すべて白鍵（幹音）。

<div class="vf-stave" data-key="G" data-scale="g/4,a/4,b/4,c/5,d/5,e/5,f#/5,g/5" data-width="440" data-height="120">♪</div>

**ト長調 G major** — 調号 ♯1。第7音の **F♯** は調号で示されるので音符には ♯ を付けない。

---

## まとめ

- **調号 → 調** は 1 対 1（長調・短調は平行調としてペア）で、全部で **15 種**（異名同音を別と数える）
- **♯ 系 7 つ・♭ 系 7 つ・調号なし 1 つ**。並ぶ順序はファ→ド→ソ→…（♯）／その逆（♭）
- **五度圏**で完全5度＝♯、完全4度＝♭ の増減として一望できる
- 描画はすべて **Bravura**（SMuFL 準拠の楽譜フォント）を **VexFlow** 経由でブラウザ内レンダリング

<p class="ks-note">短調の基準は自然短音階。和声的・旋律的短音階の変化音は臨時記号で表す。ドイツ語の H＝英 B、ドイツ語 B＝英 B♭。嬰＝♯、変＝♭。</p>
