## 手描き SVG：細胞膜の脂質二重層

<svg viewBox="0 0 520 260" width="520" style="max-width:100%">
  <defs>
    <radialGradient id="head" cx="50%" cy="35%" r="65%">
      <stop offset="0%" stop-color="#ffd27f" />
      <stop offset="100%" stop-color="#ff9d3b" />
    </radialGradient>
  </defs>
  {Array.from({ length: 13 }).map((_, i) => {
    const x = 30 + i * 37
    return (
      <g key={i}>
        {/* upper leaflet */}
        <circle cx={x} cy={70} r={12} fill="url(#head)" stroke="#7a4a10" stroke-width="1.5" />
        <line x1={x - 4} y1={82} x2={x - 4} y2={120} stroke="#c9c9c9" stroke-width="2.5" />
        <line x1={x + 4} y1={82} x2={x + 4} y2={120} stroke="#c9c9c9" stroke-width="2.5" />
        {/* lower leaflet */}
        <circle cx={x} cy={190} r={12} fill="url(#head)" stroke="#7a4a10" stroke-width="1.5" />
        <line x1={x - 4} y1={178} x2={x - 4} y2={140} stroke="#c9c9c9" stroke-width="2.5" />
        <line x1={x + 4} y1={178} x2={x + 4} y2={140} stroke="#c9c9c9" stroke-width="2.5" />
      </g>
    )
  })}
  <text x="260" y="135" text-anchor="middle" fill="#8a8a8a" font-size="13">hydrophobic core</text>
</svg>

親水性の頭部（黄）と疎水性の尾部（灰）が向かい合う二重層。JSX なので `map()` で並べられる。

## しくみ

```html
<!-- _renderer.tsx: スライドページに CDN から読み込む -->
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/molstar@5.11.0/build/viewer/molstar.css">
<script src="https://cdn.jsdelivr.net/npm/molstar@5.11.0/build/viewer/molstar.js"></script>
```

```js
// slide.js: プレースホルダ div にビューワを初期化
molstar.Viewer.create(el, { layoutShowControls: false })
  .then((viewer) => viewer.loadPdb('1CRN')) // RCSB から直接取得
```

Mol\* は **RCSB 公式ビューワの中身**。高品質カートゥーン・分子表面・環境遮蔽(SSAO) に対応。
